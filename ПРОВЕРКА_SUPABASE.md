# Проверка: почему товары не появляются

## Шаг 1. Запустить приложение и смотреть консоль

1. Откройте терминал в папке проекта.
2. Выполните: `flutter run`
3. Войдите в приложение, откройте каталог.
4. Посмотрите вывод в терминале — там должно быть одно из сообщений:

- **«ProductService: загружено X товаров из Supabase»** — всё работает, товары подгружаются.
- **«ProductService: таблица products пуста»** — в Supabase нет товаров, показываются локальные.
- **«ProductService: ошибка загрузки из Supabase: ...»** — есть ошибка, дальше будет её текст.

## Шаг 2. Если видите «ошибка загрузки»

Скопируйте текст ошибки. Частые причины:

### «Invalid API key» / «JWT»
Ключ указан неверно. В Supabase: **Project Settings** → **API**:
- Попробуйте ключ **anon** (Legacy) — длинная строка, начинается с `eyJ...`
- Или ключ **Publishable** — начинается с `sb_publishable_...`

В `lib/supabase_config.dart` вставьте тот ключ, который видите в разделе API.

### «relation "products" does not exist»
Таблица `products` не создана. В Supabase: **SQL Editor** → выполните SQL из `SUPABASE_ПОШАГОВО.md` (Часть 2).

### «permission denied» / «row-level security»
Нет политики на чтение. В Supabase: **Table Editor** → **products** → **RLS**. Должна быть политика, разрешающая SELECT для всех.

## Шаг 3. Если видите «таблица products пуста»

1. Откройте Supabase → **Table Editor** → **products**.
2. Если таблица пустая — товары не добавляются из админки.
3. Откройте `admin_supabase/index.html`, добавьте товар.
4. Должно появиться сообщение «Товар добавлен!».
5. Проверьте снова в Table Editor — должна появиться новая строка.

## Шаг 4. Попробовать Legacy-ключ

Если используется ключ `sb_publishable_...` и есть ошибки:

1. В Supabase: **Project Settings** → **API**.
2. Найдите блок **Legacy API keys** или вкладку **Legacy**.
3. Скопируйте ключ **anon** (начинается с `eyJ...`).
4. Вставьте его в `lib/supabase_config.dart` вместо текущего.
5. Перезапустите приложение: `flutter run`

## Шаг 5. Обновить каталог

На главном экране **потяните список вниз** (pull-to-refresh) — каталог перезагрузится из Supabase.

## Устройства и синхронизация в реальном времени

Чтобы работали **устройства** и **синхронизация заказов, избранного, корзины** между устройствами:

1. Выполните **`supabase_device_sessions.sql`** (таблица device_sessions).
2. Выполните **`supabase_user_data_sync.sql`** (таблицы user_orders, user_favorites, user_cart и др. + Realtime).
3. После этого:
   - все устройства отображаются в профиле и настройках;
   - заказы, избранное, корзина, адреса, карты синхронизируются между устройствами в реальном времени;
   - у каждого устройства показывается статус «В сети» / «Не в сети».
