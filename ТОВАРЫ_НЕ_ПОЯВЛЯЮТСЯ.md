# Товары не появляются в приложении — что проверить

## 1. Вставили ли вы URL и ключ в приложение?

Откройте файл **`lib/supabase_config.dart`**.

Там должно быть **ваше** (не заглушка):

```dart
static const String url = 'https://xxxxx.supabase.co';
static const String anonKey = 'eyJhbGciOiJIUzI1NiIs...';
```

Если стоит `YOUR_SUPABASE_URL` или `YOUR_SUPABASE_ANON_KEY` — приложение **не подключено** к Supabase и показывает только локальные товары.

**Что сделать:** вставьте те же URL и anon key, что в `admin_supabase/config.js`.

---

## 2. Перезапустили ли приложение после изменений?

После изменения `supabase_config.dart` нужен **полный перезапуск**:

1. Остановите приложение (Ctrl+C в терминале или кнопка Stop).
2. Запустите снова: `flutter run`

Горячая перезагрузка (Hot Reload) **не подхватывает** изменения конфига.

---

## 3. Обновите каталог вручную

На главном экране (вкладка «Каталог») **потяните список вниз** (pull-to-refresh) — каталог должен обновиться и подтянуть товары из Supabase.

---

## 4. Проверьте, что товар есть в Supabase

1. Откройте **supabase.com** → ваш проект.
2. **Table Editor** → таблица **products**.
3. Убедитесь, что там есть строки с товарами.

Если таблица пустая — товары не добавляются из админки. Проверьте, что в админке появляется сообщение «Товар добавлен!».

---

## 5. Проверьте интернет

Приложение должно иметь доступ в интернет, чтобы загрузить товары из Supabase. Проверьте Wi‑Fi или мобильный интернет.

---

## Краткий чек-лист

- [ ] В `lib/supabase_config.dart` вставлены реальные URL и anon key
- [ ] Приложение полностью перезапущено (`flutter run`)
- [ ] В Supabase в таблице `products` есть товары
- [ ] На главном экране выполнен pull-to-refresh (потянуть список вниз)
