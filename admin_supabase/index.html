Создание промокодов

Только вы можете создавать промокоды. Настройте adminSecret в config.js и выполните promo_codes_setup.sql в Supabase.

Активные промокоды

Если удаление или редактирование не работает

В Supabase → SQL Editor выполните:

-- Политика удаления
create policy "Разрешить удаление всем"
  on products for delete using (true);

-- Политика редактирования
create policy "Разрешить обновление всем"
  on products for update using (true)
  with check (true);

Или в папке admin_supabase выполните npm run setup.

Промокоды (только вы создаёте)

Выполните promo_codes_setup.sql, затем добавьте в config.js: adminSecret и adminPassword.
