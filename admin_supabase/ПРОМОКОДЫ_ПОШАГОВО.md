# Промокоды — пошаговая инструкция

## Что нужно сделать

Создать в Supabase таблицы и функции для промокодов, чтобы только вы могли их добавлять.

---

## Шаг 1. Открыть Supabase

1. Откройте браузер
2. Перейдите на **https://supabase.com**
3. Войдите в свой аккаунт
4. Выберите проект **yanikov** (или как у вас называется)

---

## Шаг 2. Открыть SQL Editor

1. В **левом меню** найдите раздел **SQL Editor**
2. Нажмите на **SQL Editor** (иконка `</>`)
3. Откроется окно с полем для ввода SQL (может быть вкладка «Untitled query»)
4. **Ничего больше нажимать не нужно** — просто кликните в большое пустое поле и вставляйте скрипт (шаг 3 ниже)

---

## Шаг 3. Скопировать SQL-скрипт

1. Откройте папку **admin_supabase** в вашем проекте
2. Откройте файл **promo_codes_setup.sql** (двойной клик или в редакторе)
3. Нажмите **Ctrl+A** (выделить всё)
4. Нажмите **Ctrl+C** (скопировать)

---

## Шаг 4. Вставить в Supabase и выполнить

1. Вернитесь в браузер — в Supabase должно быть открыто окно SQL Editor с пустым полем (или вкладка «Untitled query»)
2. **Кликните мышкой** в это большое текстовое поле (где пишется SQL)
3. Нажмите **Ctrl+V** (вставить) — скрипт появится в поле
4. Проверьте последнюю строку — там должно быть `values (1, 'LIFI')`. Если в config.js у вас другой секрет — замените LIFI на него

---

## Шаг 5. Выполнить скрипт

1. Нажмите зелёную кнопку **Run** (внизу справа)
2. Или нажмите **Ctrl+Enter**
3. Подождите 2–3 секунды
4. Должно появиться сообщение **Success** или **Success. No rows returned**

---

## Шаг 6. Проверить config.js

1. Откройте файл **admin_supabase/config.js**
2. Убедитесь, что строка `adminSecret` совпадает с тем, что вы вставили в SQL:
   ```javascript
   const adminSecret = "LIFI";
   ```
3. Если в SQL вы написали другой пароль — напишите тот же в config.js

---

## Шаг 7. Обновить админку

1. Откройте **admin_supabase/index.html** в браузере
2. Нажмите **F5** (обновить страницу)
3. Перейдите на вкладку **«Промокоды»**
4. Введите код (например **WELCOME**) и скидку (например **10**)
5. Нажмите **«Добавить промокод»**

---

## Если не работает

- Подождите 10–20 секунд после выполнения SQL и обновите страницу
- Проверьте, что в SQL и в config.js **одинаковый** секрет (одинаковые кавычки, без лишних пробелов)
- Убедитесь, что скрипт выполнился без ошибок (в Supabase не было красных сообщений)
