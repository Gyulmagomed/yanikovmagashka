# Не хватает места на диске — что сделать

Ошибка `ENOSPC: no space left on device` значит, что на диске C: почти не осталось свободного места. Нужно освободить несколько гигабайт.

---

## 1. Очистить кэш npm

В терминале (cmd) выполните:

```
npm cache clean --force
```

Это удалит старые загруженные пакеты и может освободить 100–500 МБ.

---

## 2. Очистить временные файлы Windows

1. Нажмите **Win + R**, введите **%temp%**, нажмите Enter.
2. Выделите всё (Ctrl+A) и удалите (Delete).
3. Нажмите **Win + R**, введите **temp**, нажмите Enter.
4. Удалите содержимое папки.
5. Очистите корзину.

---

## 3. Очистка диска

1. Откройте **«Этот компьютер»**.
2. Правый клик по диску **C:** → **«Свойства»**.
3. Нажмите **«Очистка диска»**.
4. Подождите анализа.
5. Отметьте галочками:
   - Временные файлы
   - Временные файлы интернета
   - Очистка корзины
   - Загруженные файлы
6. Нажмите **«ОК»** → **«Удалить файлы»**.

---

## 4. Просмотр, что занимает место

1. Откройте **Параметры** (Win + I).
2. **Система** → **Память** → **Память устройства**.
3. Посмотрите, какие разделы занимают больше всего.
4. Часто много места занимают:
   - **Загрузки** — удалите ненужные файлы
   - **Видео** — перенесите на другой диск или удалите
   - **Приложения** — удалите неиспользуемые программы

---

## 5. После освобождения места

Когда освободится хотя бы **2–3 ГБ**:

1. Закройте и откройте терминал заново.
2. Выполните:
   ```
   npm install -g firebase-tools
   ```
3. Затем:
   ```
   firebase login
   cd c:\Users\GG\telemost12_app
   firebase deploy --only hosting
   ```

---

## 6. Если не получается освободить место

Можно попробовать **CORS** (способ 2 из `ЧТО_ДЕЛАТЬ.md`), но Google Cloud SDK тоже нуждается в свободном месте.

**Вариант:** использовать другой компьютер или виртуальную машину с достаточным местом на диске для установки firebase-tools и деплоя.
