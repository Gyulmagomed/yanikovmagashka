# Как убрать ошибки при добавлении товара

Если при добавлении товара в админке появляются красные ошибки в консоли (CORS, blocked) — сделайте так.

---

## Способ 1. Разместить админку в интернете (рекомендуется)

Админка будет открываться по ссылке в браузере, и ошибки CORS пропадут.

### Шаг 1. Установить Node.js (если ещё нет)

1. Откройте: **https://nodejs.org**
2. Скачайте версию **LTS** (зелёная кнопка).
3. Установите, нажимая «Далее» везде.
4. Перезапустите компьютер (или хотя бы закрыйте и откройте терминал заново).

### Шаг 2. Установить Firebase

1. Нажмите **Win + R**, введите **cmd**, нажмите Enter.
2. В чёрном окне введите и нажмите Enter:
   ```
   npm install -g firebase-tools
   ```
3. Подождите, пока всё установится.

### Шаг 3. Войти в Firebase

1. В том же окне введите:
   ```
   firebase login
   ```
2. Откроется браузер — войдите в тот же Google-аккаунт, что и в Firebase Console.
3. Напишите в консоли, что вход выполнен.

### Шаг 4. Перейти в папку проекта

Введите (замените путь на свой, если папка в другом месте):

```
cd c:\Users\GG\telemost12_app
```

Нажмите Enter.

### Шаг 5. Разместить админку

Введите:

```
firebase deploy --only hosting
```

Нажмите Enter. Подождите 1–2 минуты.

### Шаг 6. Открыть админку

В конце команды появится ссылка, например:

```
Hosting URL: https://yanikov-shop.web.app
```

Скопируйте её и откройте в браузере. Добавляйте товары через эту ссылку — ошибок быть не должно.

---

## Способ 2. Настроить CORS (если способ 1 не подходит)

### Шаг 1. Установить Google Cloud SDK

1. Откройте: **https://cloud.google.com/sdk/docs/install**
2. Скачайте установщик для Windows.
3. Установите, следуя подсказкам.
4. В конце установки отметьте «Run gcloud init» и нажмите «Finish».

### Шаг 2. Войти в Google Cloud

1. Откроется окно терминала.
2. Войдите в Google-аккаунт (тот же, что в Firebase).
3. Выберите проект **yanikov-shop**.

### Шаг 3. Применить настройки CORS

1. Откройте терминал (cmd).
2. Перейдите в папку admin:
   ```
   cd c:\Users\GG\telemost12_app\admin
   ```
3. Введите команду:
   ```
   gsutil cors set cors.json gs://yanikov-shop.firebasestorage.app
   ```
4. Нажмите Enter.
5. Обновите страницу админки (F5) и попробуйте снова добавить товар.

## Кратко

| Что делать | Команды |
|------------|---------|
| **Способ 1** (проще) | `npm install -g firebase-tools` → `firebase login` → `cd c:\Users\GG\telemost12_app` → `firebase deploy --only hosting` |
| **Способ 2** | Установить Google Cloud SDK → `cd admin` → `gsutil cors set cors.json gs://yanikov-shop.firebasestorage.app` |

---

## Если что-то не получается

- **«npm не найден»** — установите Node.js (Шаг 1 способа 1).
- **«firebase не найден»** — закройте и откройте терминал заново после установки.
- **«gsutil не найден»** — установите Google Cloud SDK (способ 2).
- **Ошибка при deploy** — проверьте, что вы вошли в Firebase (`firebase login`) и что в папке есть файл `firebase.json`.
