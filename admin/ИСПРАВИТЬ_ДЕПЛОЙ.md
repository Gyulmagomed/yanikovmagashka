# Ошибка при firebase deploy — что сделать

## Шаг 1. Включить Firebase Hosting API

1. Откройте в браузере:
   **https://console.cloud.google.com/apis/library/firebasehosting.googleapis.com?project=yanikov-shop**

2. Убедитесь, что выбран проект **yanikov-shop** (сверху страницы).

3. Нажмите кнопку **«Включить»** (Enable).

4. Подождите 1–2 минуты.

---

## Шаг 2. Повторить деплой

В терминале (в папке `c:\Users\GG\telemost12_app`):

```
firebase deploy --only hosting --project yanikov-shop
```

---

## Если ошибка осталась

### Вариант А. Обновить вход в Firebase

```
firebase logout
firebase login
```

Войдите в тот аккаунт, где создан проект yanikov-shop.

### Вариант Б. Проверить интернет и VPN

Отключите VPN, если включён. Проверьте, что сайты Google открываются.

### Вариант В. Инициализировать Hosting заново

```
firebase init hosting
```

- Выберите проект: **yanikov-shop**
- Public directory: введите **admin**
- Single-page app: **No**
- Overwrite index.html: **No**

Затем снова:

```
firebase deploy --only hosting
```
