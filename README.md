YANIKOV Online Store

Кроссплатформенное приложение интернет-магазина, разработанное на Flutter, с поддержкой мобильных платформ, веб-версии и десктопа.
Проект включает клиентское приложение для пользователей и административную часть для управления товарами.

🚀 Возможности

Просмотр каталога товаров

Добавление товаров и управление ассортиментом

Административная панель для управления магазином

Хранение и синхронизация данных через Supabase

Аутентификация пользователей

Работа с изображениями товаров

Поддержка нескольких платформ

🧰 Технологии

Основной стек проекта:

Flutter / Dart — разработка кроссплатформенного приложения

Firebase — аутентификация, правила безопасности, облачная инфраструктура

Supabase — база данных и backend-сервисы

HTML / JavaScript — веб-часть приложения

Проект поддерживает следующие платформы:

Android

iOS

Web

Windows

macOS

Linux

📁 Структура проекта
lib/                — основной код приложения
admin/              — административная панель
assets/             — изображения и статические ресурсы
web/                — веб-версия приложения
android/            — конфигурация Android
ios/                — конфигурация iOS
supabase/           — SQL и настройки базы данных
test/               — тесты
⚙️ Установка и запуск
1. Клонировать репозиторий
git clone https://github.com/Gyulmagomed/yanikovmagashka.git
cd yanikovmagashka
2. Установить зависимости
flutter pub get
3. Запустить приложение
flutter run
🔐 Настройка backend

Перед запуском необходимо настроить:

Supabase (URL и API ключи)

Firebase (firestore и storage rules)

Инструкции находятся в файлах:

SUPABASE_ИНСТРУКЦИЯ.md

SUPABASE_ПОШАГОВО.md

ADMIN_SETUP.md

📦 Основные функции администратора

управление товарами

добавление и редактирование каталога

синхронизация данных с базой

управление пользовательскими данными
