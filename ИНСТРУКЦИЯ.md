# Инструкция: как добавить товары через админку и увидеть их в приложении

Пошаговая инструкция для настройки всего с нуля.

---

## Шаг 1. Создать проект Firebase

1. Откройте браузер и перейдите на **https://console.firebase.google.com**
2. Войдите в Google-аккаунт.
3. Нажмите **«Создать проект»** (или «Add project»).
4. Введите название, например: **yanikov-shop**
5. Нажмите **«Продолжить»** → **«Создать проект»** → дождитесь создания.
6. Нажмите **«Продолжить»**.

---

## Шаг 2. Включить Firestore (база данных)

1. В левом меню выберите **«Сборка»** → **«Firestore Database»**.
2. Нажмите **«Создать базу данных»**.
3. Выберите **«Начать в тестовом режиме»** → **«Далее»**.
4. Выберите регион (например, **europe-west1**) → **«Включить»**.
5. Дождитесь создания базы.

---

## Шаг 3. Включить Storage (хранилище для фото)

1. В левом меню выберите **«Сборка»** → **«Storage»**.
2. Нажмите **«Начать»**.
3. Оставьте **«Начать в тестовом режиме»** → **«Далее»**.
4. Нажмите **«Готово»**.

---

## Шаг 4. Добавить веб-приложение (для админки)

1. Нажмите на **шестерёнку** рядом с «Обзор проекта» → **«Настройки проекта»**.
2. Прокрутите вниз до раздела **«Ваши приложения»**.
3. Нажмите на иконку **`</>`** (веб).
4. Введите название приложения, например: **yanikov-admin**.
5. **Не включайте** Firebase Hosting.
6. Нажмите **«Зарегистрировать приложение»**.
7. Появится объект `firebaseConfig` с данными. **Скопируйте его целиком** (Ctrl+C).  
   Пример:
   ```javascript
   const firebaseConfig = {
     apiKey: "AIzaSyB...",
     authDomain: "yanikov-shop.firebaseapp.com",
     projectId: "yanikov-shop",
     storageBucket: "yanikov-shop.firebasestorage.app",
     messagingSenderId: "123456789",
     appId: "1:123456789:web:abc123"
   };
   ```
8. Нажмите **«Продолжить»** → **«Перейти в консоль»**.

## Шаг 5. Вставить конфиг в админку

1. Откройте папку проекта: **`c:\Users\GG\telemost12_app`**
2. Зайдите в папку **`admin`**
3. Откройте файл **`config.js`** в любом редакторе (Блокнот, VS Code, Cursor).
4. Удалите всё содержимое и вставьте скопированный `firebaseConfig` из Firebase.
5. Сохраните файл (Ctrl+S).

## Шаг 6. Настроить Flutter-приложение для Firebase

1. Откройте **терминал** (PowerShell или CMD) в папке проекта:
   ```
   c:\Users\GG\telemost12_app
   ```

2. Установите FlutterFire CLI (один раз):
   ```
   dart pub global activate flutterfire_cli
   ```

3. Выполните настройку Firebase:
   ```
   flutterfire configure
   ```

4. Выберите ваш проект Firebase (стрелками вверх/вниз, Enter).
5. Отметьте платформы (Android, iOS, Web — можно пробелом, Enter для подтверждения).
6. Дождитесь завершения. Будет создан/обновлён файл **`lib/firebase_options.dart`**.

   Или через терминал:
   ```

   npx serve .
   ```
   Затем откройте в браузере: **http://localhost:3000**

## Шаг 8. Добавить первый товар

1. В админке заполните форму:
   - **Название:** например, «Футболка чёрная»
   - **Цена:** 2990 (только число, без пробелов)
   - **Категория:** выберите из списка
   - **Описание:** по желанию
   - **Размеры:** S, M, L, XL (через запятую)
   - **Фото:** нажмите «Выбрать файл» и выберите картинку

2. Нажмите **«Добавить товар»**.

3. Должно появиться сообщение: **«Товар добавлен! Он появится в приложении»**.

---

## Шаг 9. Увидеть товар в приложении

1. Запустите приложение:
   ```
   cd c:\Users\GG\telemost12_app
   flutter run
   ```

2. Войдите в приложение (авторизация).

3. На главном экране потяните список вниз (pull-to-refresh) или перезапустите приложение.

4. Новый товар должен появиться в каталоге.

---

## Шаг 10. Настроить CORS для Storage (если есть ошибки при загрузке фото)

**Подробная инструкция:** откройте файл **`admin/ЧТО_ДЕЛАТЬ.md`** — там пошагово расписано, что делать.

Если при добавлении товара появляются ошибки **CORS** в консоли браузера:

1. Установите **Google Cloud SDK**: https://cloud.google.com/sdk/docs/install  
   (или только gsutil, если не нужен полный SDK)

2. Откройте терминал в папке **`admin`**:
   ```
   cd c:\Users\GG\telemost12_app\admin
   ```

3. Выполните команду (подставьте свой projectId, если другой):
   ```
   gsutil cors set cors.json gs://yanikov-shop.firebasestorage.app
   ```

4. Если gsutil не найден — авторизуйтесь в Google Cloud:
   ```
   gcloud auth login
   gcloud config set project yanikov-shop
   gsutil cors set cors.json gs://yanikov-shop.firebasestorage.app
   ```

5. Обновите страницу админки и попробуйте снова добавить товар.

**Вариант без gsutil (проще):** разверните админку на Firebase Hosting — CORS тогда не мешает:

1. Установите Firebase CLI: `npm install -g firebase-tools`
2. Войдите: `firebase login`
3. В папке проекта выполните: `firebase deploy --only hosting`
4. Откройте админку по ссылке из вывода команды (например `https://yanikov-shop.web.app`)

## Частые проблемы

### «Настройте config.js с данными Firebase»
- Убедитесь, что в `admin/config.js` вставлен полный объект `firebaseConfig` из Firebase Console.
- Проверьте, что нет лишних символов и кавычки закрыты.

### Ошибка CORS при добавлении товара (blocked by CORS policy)
- Firebase Storage блокирует запросы с локального сервера (127.0.0.1:5500).
- Решение: выполните **Шаг 10** выше (настроить CORS через gsutil) или разверните админку на Firebase Hosting.

### Товары не появляются в приложении
- Убедитесь, что вы выполнили `flutterfire configure`.
- Проверьте интернет на устройстве/эмуляторе.
- Перезапустите приложение или сделайте pull-to-refresh на главном экране.

### Ошибка при добавлении товара
- Проверьте, что Firestore и Storage включены в Firebase Console.
- Убедитесь, что в Firestore и Storage выбран тестовый режим (для начала).
