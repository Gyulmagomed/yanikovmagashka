# Исправления проблемы автоматического выхода из аккаунта

## Что было исправлено в коде

### 1. **main.dart** — отключена обработка сессии из URL на web
- Добавлено `authOptions: FlutterAuthClientOptions(detectSessionInUri: !kIsWeb)`
- На web Supabase больше не парсит hash в URL (`#access_token=...`), что могло вызывать конфликты и sign out
- На мобильных платформах deep links по-прежнему работают

### 2. **auth_screen.dart** — убран вызов `resetForLogout()` в initState
- Удалён `SessionsService.instance.resetForLogout()` при открытии экрана входа
- Этот вызов мог вызывать побочные эффекты при повторном входе

### 3. **auth_service.dart** — удалены debug-логи
- Убраны `debugPrint` из метода `logout()`

### 4. **main.dart** — удалён слушатель onAuthStateChange
- Убран временный debug-код для отладки

---

## Что проверить вручную

### 1. Очистить данные браузера (если тестируете на web)
1. Откройте DevTools (F12)
2. Application → Storage → **Clear site data**
3. Или вручную очистите Local Storage для вашего localhost

### 2. Проверить URL
- Убедитесь, что в адресной строке нет лишнего после `#` (например, `#access_token=...`)
- Если есть — удалите всё после `#` и обновите страницу

### 3. Полный перезапуск приложения
- Остановите приложение полностью (не hot reload)
- Запустите заново: `flutter run -d edge` или через IDE

### 4. Если проблема останется — добавить отладку
В `lib/services/auth_service.dart` в начале метода `logout()` временно добавьте:
```dart
debugPrint('AuthService.logout вызван из: ${StackTrace.current}');
```
Это покажет, откуда вызывается выход.

---

## Текущая логика выхода

- **Кнопка «Выйти»** (HomeScreen) — вызывает `AuthService.logout()` и переход на экран входа
- **«Завершить все сеансы»** (DevicesScreen) — вызывает `terminateAllOther()`, затем `logout()` и переход на экран входа
- **Автоматический выход** — отключён (listener `sessionTerminated` удалён ранее)
