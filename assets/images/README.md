# Изображения для главного экрана

## Фон баннера «Новая коллекция / Весна 2025»

- **Имя файла:** строго `hero_banner.jpg` **или** `hero_banner.png`
- **Папка:** эта же папка `assets/images/` (рядом с этим README)
- **Размер:** 1200×600 или 800×400 px (горизонтальный)

**Важно:** после добавления или смены файла нужно **полностью перезапустить приложение** (Stop → Run), а не только Hot Reload — иначе новое фото не подхватится.
