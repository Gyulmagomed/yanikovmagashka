# Фотографии товаров YANIKOV

Положите в эту папку изображения товаров. Имя файла — **номер товара** + `.jpg` (или `.png`).

## Формат

- **Имя файла:** `1.jpg`, `2.jpg`, … `40.jpg`
- **Рекомендуемый размер:** 800×800 px (квадрат) или 600×800 px
- **Форматы:** JPG или PNG
