# Supabase — пошаговая инструкция

Подробная инструкция: что нажимать и что вводить на сайте supabase.com

---

## Часть 1. Регистрация и создание проекта

### Шаг 1.1. Открыть сайт

1. Откройте браузер.
2. Перейдите на **https://supabase.com**
3. Нажмите зелёную кнопку **«Start your project»** (в правом верхнем углу).

### Шаг 1.2. Войти

1. Выберите способ входа:
   - **Sign in with GitHub** — если есть аккаунт GitHub
   - **Sign in with Google** — войти через Google
   - **Sign in with Email** — ввести email и пароль
2. Войдите в аккаунт.

### Шаг 1.3. Создать организацию (если просят)

1. Если появится окно «Create a new organization»:
   - **Organization name:** введите **yanikov** (или любое название)
   - Нажмите **Create organization**

### Шаг 1.4. Создать новый проект

1. Нажмите **«New Project»** (или «New project»).
2. Если спросят, выберите организацию (если она одна — выберется автоматически).
3. Заполните форму:
   - **Name:** введите **yanikov-shop**
   - **Database Password:** придумайте пароль (например, `MyPass123!`) и **обязательно сохраните** его в блокноте
   - **Region:** выберите **Frankfurt** или **London** (ближе к России)
4. Нажмите **«Create new project»**.
5. Подождите 1–2 минуты, пока проект создаётся (появится зелёная галочка).

## Часть 2. Создание таблицы для товаров

### Шаг 2.1. Открыть SQL Editor

1. В левом меню нажмите **«SQL Editor»** (иконка с символом `</>`).
2. Нажмите **«New query»** (или кнопку **+ New query**).

### Шаг 2.2. Вставить и выполнить SQL

1. В большое текстовое поле вставьте этот код (Ctrl+V):

```
create table products (
  id uuid default gen_random_uuid() primary key,
  title text not null,
  price integer not null,
  category text not null,
  description text,
  sizes text[],
  image_url text,
  created_at timestamptz default now()
);

alter table products enable row level security;

create policy "Разрешить чтение всем"
  on products for select
  using (true);

create policy "Разрешить добавление всем"
  on products for insert
  with check (true);
```

2. Нажмите **«Run»** (или Ctrl+Enter).
3. Должно появиться сообщение **«Success. No rows returned»** — это нормально.

### Шаг 2.3. Проверить таблицу

1. В левом меню нажмите **«Table Editor»**.
2. В списке таблиц должна появиться **products**.
3. Нажмите на неё — таблица пустая, это нормально.

## Часть 3. Создание хранилища для фото

### Шаг 3.1. Создать bucket

1. В левом меню нажмите **«Storage»**.
2. Нажмите **«New bucket»**.
3. В поле **Name** введите: **products**
4. Включите переключатель **«Public bucket»** (должен стать синим/зелёным).
5. Нажмите **«Create bucket»**.

### Шаг 3.2. Разрешить загрузку файлов

1. Нажмите на созданный bucket **products**.
2. Перейдите на вкладку **«Policies»** (Политики).
3. Нажмите **«New Policy»**.
4. Выберите **«For full customization»** (Полная настройка).
5. В поле **Policy name** введите: **Allow upload**
6. В выпадающем списке **Allowed operation** выберите **INSERT**.
7. В поле **Target roles** оставьте **public**.
8. В блоке **WITH CHECK expression** введите **только** (копируйте, не печатайте вручную):  
   `bucket_id = 'products'`  
   ⚠️ Без скобок вокруг, без точки с запятой в конце. Кавычки вокруг `products` — обычные прямые `'`.
9. Нажмите **«Review»** → **«Save policy»**.

### Шаг 3.3. Разрешить чтение файлов

Эта политика нужна, чтобы приложение и админка могли **открывать и показывать** загруженные фото.

1. Убедитесь, что вы внутри bucket **products** (нажмите на него в списке).
2. Откройте вкладку **«Policies»** (Политики).
3. Нажмите **«New Policy»**.
4. Выберите **«For full customization»**.
5. Заполните поля по очереди:

   | Поле | Что ввести |
   |------|------------|
   | **Policy name** | `Allow read` |
   | **Allowed operation** | выберите **SELECT** (в выпадающем списке) |
   | **Target roles** | оставьте `public` |
   | **USING expression** | `bucket_id = 'products'` |

6. В поле **USING expression** введите **только** (скопируйте):  
   `bucket_id = 'products'`  
   Без скобок, без точки с запятой.
7. Нажмите **«Review»**.
8. Нажмите **«Save policy»**.

**Что это даёт:** любой пользователь (включая приложение) сможет получать ссылки на фото и загружать их для просмотра.

## Часть 4. Взять URL и ключ

### Шаг 4.1. Где находятся настройки

1. Откройте ваш проект на **supabase.com** (должны быть на главной странице проекта).
2. Посмотрите на **левую боковую панель** (меню).
3. В самом **низу** левого меню найдите **иконку шестерёнки** и надпись **«Project Settings»**.
4. Нажмите на **«Project Settings»** (или на шестерёнку).
5. Откроется страница настроек. В **левой части** этой страницы появится подменю:
   - General
   - **API** ← нажмите сюда
   - Database
   - Auth
   - Storage
   - и т.д.
6. Нажмите **«API»**.

### Шаг 4.2. Скопировать URL

1. На странице API вверху найдите блок **«Project URL»**.
2. Под ним будет ссылка вида `https://xxxxxxxx.supabase.co`.
3. Справа от ссылки — **иконка копирования** (два прямоугольника).
4. Нажмите на неё — URL скопируется.
5. Вставьте в блокнот (Ctrl+V) — это ваш **URL**.

### Шаг 4.3. Скопировать anon key

1. Прокрутите страницу вниз до блока **«Project API keys»**.
2. Там будут два ключа:
   - **anon** **public** — это нужный (первый)
   - service_role — не используйте
3. Рядом с ключом **anon** по умолчанию показаны звёздочки `••••••••`.
4. Нажмите **«Reveal»** (Показать) — появится длинная строка, начинается с `eyJ...`.
5. Нажмите иконку **копирования** справа от ключа.
6. Вставьте в блокнот — это ваш **anon key**.

### Если не видите Project Settings

- Убедитесь, что вы **внутри проекта** (слева вверху должно быть название проекта, например yanikov-shop).
- Если видите список проектов — нажмите на нужный проект, чтобы войти в него.
- Шестерёнка и Project Settings всегда в **нижней части** левого меню.

## Часть 5. Вставить данные в проект

### Шаг 5.1. Админка (admin_supabase/config.js)

1. Откройте папку **`c:\Users\GG\telemost12_app\admin_supabase`**.
2. Откройте файл **config.js** в редакторе (Блокнот, Cursor и т.п.).
3. Замените `YOUR_SUPABASE_URL` на ваш URL (из шага 4.2).
4. Замените `YOUR_SUPABASE_ANON_KEY` на ваш anon key.
5. Должно получиться примерно так:

```javascript
const supabaseConfig = {
  url: "https://abcdefgh.supabase.co",
  anonKey: "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
};
```

6. Сохраните файл (Ctrl+S).

### Шаг 5.2. Приложение (lib/supabase_config.dart)

1. Откройте папку **`c:\Users\GG\telemost12_app\lib`**.
2. Откройте файл **supabase_config.dart**.
3. Замените `YOUR_SUPABASE_URL` на ваш URL.
4. Замените `YOUR_SUPABASE_ANON_KEY` на ваш anon key.
5. Сохраните файл.

## Часть 6. Проверить работу

### Шаг 6.1. Добавить товар через админку

1. Откройте файл **`admin_supabase\index.html`** двойным кликом (откроется в браузере).
2. Заполните форму:
   - Название: **Тестовый товар**
   - Цена: **1000**
   - Категория: выберите любую
   - Выберите любое фото с компьютера
3. Нажмите **«Добавить товар»**.
4. Должно появиться сообщение **«Товар добавлен!»**.

### Шаг 6.2. Проверить в Supabase

1. Вернитесь на supabase.com → ваш проект.
2. **Table Editor** → таблица **products** — должна появиться новая строка.
3. **Storage** → bucket **products** — должно появиться загруженное фото.

### Шаг 6.3. Проверить в приложении

1. Откройте терминал.
2. Выполните: `cd c:\Users\GG\telemost12_app`
3. Выполните: `flutter run`
4. Войдите в приложение и откройте каталог — товар должен отображаться.

## Краткая шпаргалка

| Где на Supabase | Что делать |
|-----------------|------------|
| New Project | Создать проект, придумать пароль |
| SQL Editor | Вставить SQL для таблицы products, нажать Run |
| Storage → New bucket | Создать bucket «products», включить Public |
| Storage → Policies | Добавить политики Allow upload и Allow read |
| Settings → API | Скопировать URL и anon key |
| admin_supabase/config.js | Вставить URL и anon key |
| lib/supabase_config.dart | Вставить URL и anon key |

## Если что-то не работает

- **«unterminated quoted string» / «Error adding policy»** — в поле WITH CHECK или USING вводите **только** `bucket_id = 'products'`. Не добавляйте лишние скобки `()`, точку с запятой `;`, не используйте «умные» кавычки. Лучше скопируйте выражение из инструкции выше.

- **«Invalid API key»** — проверьте, что скопировали ключ **anon public** целиком, без пробелов.
- **«Failed to fetch»** — проверьте интернет, отключите VPN.
- **Ошибка при загрузке фото** — проверьте, что создали обе политики в Storage (upload и read).
- **Товар не появляется в приложении** — проверьте, что в `supabase_config.dart` вставлены те же данные, что и в config.js.
