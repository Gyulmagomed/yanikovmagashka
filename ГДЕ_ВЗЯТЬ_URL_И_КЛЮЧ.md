# Где взять URL и KEY — пошагово

Подробная инструкция: где найти данные в Supabase и куда их вставить в проекте.

---

## ЧАСТЬ A. Взять URL и KEY в Supabase

### Шаг 1. Открыть Supabase

1. Откройте браузер.
2. Перейдите на **https://supabase.com**
3. Нажмите **Sign in** (если ещё не вошли).
4. Войдите в аккаунт.

### Шаг 2. Открыть свой проект

1. На главной странице Supabase вы увидите список проектов.
2. Нажмите на **название вашего проекта** (например, yanikov-shop).
3. Откроется панель проекта (слева меню, справа контент).

### Шаг 3. Открыть настройки проекта

1. Посмотрите на **левое меню** (вертикальная полоска слева).
2. Прокрутите меню **вниз до самого конца**.
3. Внизу найдите пункт **«Project Settings»** (или иконку шестерёнки).
4. Нажмите на **«Project Settings»**.

### Шаг 4. Открыть раздел API

1. Откроется страница настроек.
2. Слева появится **подменю** с разделами:
   - General
   - **API** ← нажмите сюда
   - Database
   - Auth
   - Storage
   - и другие
3. Нажмите на **«API»**.

### Шаг 5. Скопировать URL

1. Вверху страницы найдите блок **«Project URL»**.
2. Под заголовком будет ссылка, например:  
   `https://irtfzvbisnrbqjsunelo.supabase.co`
3. Справа от ссылки — **иконка копирования** (два overlapping прямоугольника).
4. Нажмите на неё — URL скопируется в буфер обмена.
5. Вставьте в блокнот (Ctrl+V), чтобы не потерять.

### Шаг 6. Скопировать ключ (anon key)

1. Прокрутите страницу вниз.
2. Найдите блок **«Project API keys»** или **«API Keys»**.
3. Там будут один или несколько ключей. Нужен ключ **anon** (public).

**Вариант 1 — если видите ключ «anon» или «anon public»:**
- Рядом с ключом по умолчанию показаны звёздочки `••••••••`
- Нажмите **«Reveal»** (Показать)
- Появится длинная строка (начинается с `eyJ...` или `sb_publishable_...`)
- Нажмите иконку **копирования** справа от ключа

**Вариант 2 — если есть вкладка «Legacy»:**
- Перейдите на вкладку **«Legacy»**
- Найдите ключ **«anon»** **«public»**
- Нажмите **Reveal** → скопируйте

4. Вставьте ключ в блокнот (Ctrl+V).

## ЧАСТЬ B. Вставить URL и KEY в проект

Нужно вставить данные в **два файла**.

---

### Файл 1: admin_supabase/config.js

**Назначение:** админка (сайт для добавления товаров).

**Где файл:**  
`c:\Users\GG\telemost12_app\admin_supabase\config.js`

**Как открыть:**
1. Откройте папку `c:\Users\GG\telemost12_app\admin_supabase`
2. Правый клик на файл `config.js`
3. Выберите «Открыть с помощью» → Блокнот, Cursor или VS Code

**Что внутри сейчас:**
```javascript
const supabaseConfig = {
  url: "YOUR_SUPABASE_URL",
  anonKey: "YOUR_SUPABASE_ANON_KEY"
};
```

**Что должно быть (подставьте свои данные):**
```javascript
const supabaseConfig = {
  url: "https://irtfzvbisnrbqjsunelo.supabase.co",
  anonKey: "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.xxxx..."
};
```

**Важно:**
- URL — в кавычках, без пробелов в начале и конце
- anonKey — в кавычках, ключ целиком, без пробелов
- Между `url` и `anonKey` — запятая
- В конце `};` — точка с запятой и закрывающая скобка

**Сохраните файл** (Ctrl+S).

---

### Файл 2: lib/supabase_config.dart

**Назначение:** приложение Flutter (мобильное приложение).

**Где файл:**  
`c:\Users\GG\telemost12_app\lib\supabase_config.dart`

**Как открыть:**
1. Откройте папку `c:\Users\GG\telemost12_app\lib`
2. Откройте файл `supabase_config.dart` в Cursor или любом редакторе

**Что внутри сейчас:**
```dart
class SupabaseConfig {
  static const String url = 'YOUR_SUPABASE_URL';
  static const String anonKey = 'YOUR_SUPABASE_ANON_KEY';
  ...
}
```

**Что должно быть (подставьте свои данные):**
```dart
class SupabaseConfig {
  static const String url = 'https://irtfzvbisnrbqjsunelo.supabase.co';
  static const String anonKey = 'eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.xxxx...';
  ...
}
```

**Важно:**
- URL и anonKey — в **одинарных** кавычках `'...'`
- Те же самые значения, что в config.js
- Без лишних пробелов

**Сохраните файл** (Ctrl+S).

## ЧАСТЬ C. Проверить, что всё работает

### 1. Добавить товар через админку

1. Откройте файл `admin_supabase\index.html` двойным кликом (откроется в браузере).
2. Заполните форму и добавьте товар.
3. Должно появиться сообщение **«Товар добавлен!»**.

### 2. Проверить в Supabase

1. Вернитесь на supabase.com → ваш проект.
2. **Table Editor** → таблица **products**.
3. Должна появиться новая строка с товаром.

### 3. Запустить приложение

1. Откройте терминал.
2. Выполните:
   ```
   cd c:\Users\GG\telemost12_app
   flutter run
   ```
3. Войдите в приложение.
4. Откройте вкладку **Каталог**.
5. **Потяните список вниз** (pull-to-refresh).
6. Товар из Supabase должен появиться.

## Шпаргалка: куда что вставить

| Файл | URL | KEY |
|------|-----|-----|
| `admin_supabase/config.js` | В `url: "..."` | В `anonKey: "..."` |
| `lib/supabase_config.dart` | В `url = '...'` | В `anonKey = '...'` |

**Оба файла** должны содержать **одинаковые** URL и KEY.

---

## Если не работает

1. **Перезапустите приложение** — остановите (Ctrl+C) и снова `flutter run`.
2. **Проверьте кавычки** — в config.js двойные `"`, в supabase_config.dart одинарные `'`.
3. **Проверьте ключ** — скопирован целиком, без пробелов в начале и конце.
4. **Попробуйте Legacy-ключ** — если ключ `sb_publishable_...` не работает, в Supabase найдите ключ **anon** (Legacy), который начинается с `eyJ...`.
